# MLX Whisper Skill

Локальное распознавание речи на Apple Silicon через mlx-whisper. Единственная функция:
аудио → один MD-транскрипт `~/result-mlx-whisper/YYYY-MM-DD_<имя>.md`. Коррекции текста
в скриптах нет — правки ослышек и терминов вносит вызывающий агент в своём пайплайне
(например, brain-summary правит копию транскрипта в Brain). Модель выбирается по языку:
русский — специализированная whisper-podlodka-turbo q8, все остальные — мультиязычная
whisper-large-v3-turbo-8bit. Модель занимает RAM только на время процесса (~1.85 ГБ пик),
демонов и резидентных процессов нет.

## Environment

- CLI: `mlx_whisper` (uv tool `mlx-whisper`, окружение изолировано, обновление: `uv tool upgrade mlx-whisper`)
- Модели — выбор АВТОМАТИЧЕСКИЙ по `--language` (оба скрипта), явный `--model` перекрывает:
  - **ru → whisper-podlodka-turbo q8 (8 бит)** локально в
    `~/.local/share/models/whisper-podlodka-turbo-MLX-q8/` (config.json + weights.safetensors, 824 МБ).
    Источник: evilfreelancer/whisper-podlodka-turbo-MLX (q8/), база bond005/whisper-podlodka-turbo.
    q8 быстрее fp16 при совпадении текста 99.8%. fp16 лежит рядом в
    `~/.local/share/models/whisper-podlodka-turbo-MLX-fp16/` — передать путь явно через `--model`.
  - **все остальные языки → whisper-large-v3-turbo-8bit** локально в
    `~/.local/share/models/whisper-large-v3-turbo-8bit/` (config.json + weights.safetensors, ~809 МБ).
    Источник: mlx-community/whisper-large-v3-turbo-8bit (файл model.safetensors сохранён как
    weights.safetensors — такого имени ждёт mlx_whisper).
- Тянет ffmpeg для декодирования не-wav аудио; wav 16k mono берёт как есть
- **Пути**: `$HERMES_HOME` — корень активного профиля Hermes (env-переменная, раскрывается shell-ом, профиль-независима); скрипты скилла — `$HERMES_HOME/skills/media/mlx-whisper/scripts/`
- Тест-эталон: 15.7 c русская речь → чистый текст за 4.6 c (RAM 1.85 ГБ)

## When to Use

- «распознай/транскрибируй аудио/голосовое/запись» — любой локальный файл (wav/mp3/m4a/mp4/ogg)
- речь на любом языке (ru — podlodka q8, остальные — large-v3-turbo-8bit); длинные записи; нужны субтитры srt/vtt или таймстампы
- Don't use for: диаризация спикеров (кто говорил), живые стримы, коррекция текста транскрипта (это задача вызывающего скилла)

## Quick Reference

**Основной путь — пайплайн VAD+STT (скрипт `vad_transcribe.py`), ОДИН ВЫЗОВ:**

```bash
~/.local/share/uv/tools/mlx-whisper/bin/python \
  $HERMES_HOME/skills/media/mlx-whisper/scripts/vad_transcribe.py <аудио> [ещё...] --language ru \
  [--meta-title "..." --meta-author "..." --meta-date YYYY-MM-DD --meta-url "..."]
# результат: ~/result-mlx-whisper/YYYY-MM-DD_<имя-аудио>.md и строка OK <путь> в выводе
```

Этапы: Silero VAD (паузы/эффекты отрезаются) → нарезка ≤28 с → mlx_whisper.transcribe() в одном
процессе (`condition_on_previous_text=False`) → MD на диск. Больше скрипт ничего не делает.

**Запуск под скиллы-потребители — ОДИН флаг `--for <skill>`** (специфика режимов живёт
только здесь; скиллы-потребители свои комбинации флагов не описывают, а ссылаются на
этот раздел):

- `--for brain-summary` — MD-транскрипт (поведение по умолчанию; флаг опционален,
  только фиксирует режим). Шапка контент-метаданных — параметрами `--meta-*` (см. ниже).
- `--for multilingual-audio-replacement` — MD + `<имя>.segments.json`
  (`{"file", "segments": [{"start", "end", "text", "logprob"}, ...]}`, тайминги в секундах)
  — вход для пайплайна замены аудио. Эквивалент `--debug-segments`.
- `--for translated-video-subtitles` — без VAD и MD: весь файл целиком с word
  timestamps, один JSON (`~/result-mlx-whisper/<имя>.json`: сегменты с таймингами +
  пословные тайминги) — вход для построения субтитров; srt/vtt/txt/tsv не пишутся,
  они дублируют JSON. Режим рассчитан на вырезанные клипы: длинное аудио
  целиком без VAD склонно к петлям-галлюцинациям.

**Формат MD-результата:** шапка = блок контент-метаданных (Название/Автор/Дата публикации/Ссылка —
из `--meta-*`) + технические строки (дата, источник, длительность, модель, время этапов); далее
транскрипт блоками ~60 с. Новый блок начинается на предложении, старт которого БЛИЖЕ всего к
«старт предыдущего блока + 60 с» (детерминированный `group_into_blocks`, без модели). Каждый
блок — одна строка `**mm:ss** текст` + ПУСТАЯ СТРОКА после (всегда, без исключений). Хвост
<20 с вливается в предыдущий блок (если результат ≤80 с).

- `--language` указывать явно всегда — от него зависит и модель, и качество.
- `--meta-title/--meta-author/--meta-date/--meta-url` — контент-метаданные для шапки MD.
  Блок идёт в шапке ПЕРВЫМ; строка «Название» пишется всегда (без `--meta-title` — имя файла
  с расширением), остальные — только когда значение передано.
- **ГЕЙТ — пустые метаданные запрещены**: каждый `--meta-*` либо не передаётся, либо несёт
  непустое значение (скрипт падает с ошибкой на пустой строке). Если метаданные частично или
  полностью определить нельзя — ЗАПРОСИТЬ недостающие у пользователя, предложив дефолты:
  название — имя файла с расширением; автор — unknown; дата публикации — текущая дата;
  ссылка — переданная пользователем или полный относительный путь к файлу.
- `--debug-segments` — дополнительно пишет `<имя>.segments.json` (контракт для других скиллов,
  см. ниже). В обычных запусках не нужен.
- `--for <skill>` — специфика запуска под скилл-потребителя одним флагом (см. раздел выше).
- `--no-correct` — флаг-заглушка для совместимости вызовов, ни на что не влияет.
- Длинные файлы — только `terminal(background=true, notify_on_complete=true)` + `process wait`.
  Без `notify_on_complete=true` процесс завершится молча, а окно wait зажимается до 180 с.

**Быстрый MD без VAD** (сплошной текст + таблица сегментов):
`python3 $HERMES_HOME/skills/media/mlx-whisper/scripts/transcribe_to_md.py <аудио>`

**Сырой mlx_whisper** (когда MD не нужен — srt, перевод, отладка). Путь модели выбрать по
языку: ru → `~/.local/share/models/whisper-podlodka-turbo-MLX-q8`, остальные →
`~/.local/share/models/whisper-large-v3-turbo-8bit`:

```bash
# субтитры + таймстампы слов (пример для ru)
mlx_whisper --model ~/.local/share/models/whisper-podlodka-turbo-MLX-q8 \
  --language ru --condition-on-previous-text False \
  --output-format srt --word-timestamps True --output-dir /tmp/stt <аудио>

# форматы вывода: txt, vtt, srt, tsv, json, all (json содержит сегменты с вероятностями)
# перевод ru→en: --task translate (обратно en→ru НЕ умеет)
# фрагмент файла: --clip-timestamps "30"  (формат mm:ss CLI НЕ понимает — только секунды)
# промпт-контекст для стиля: --initial-prompt "..." (термины НЕ исправляет)
```

## Выходные артефакты (контракт для других скиллов)

Другие скиллы (напр. `multilingual-audio-replacement`, `translated-video-subtitles`)
получают STT через загрузку этого скилла (`skill_view media/mlx-whisper`) и запуск по
его Quick Reference — скрипты этого скилла чужими скиллами напрямую не вызываются.
Ниже — стабильный контракт ВЫХОДНЫХ артефактов и семантики:

- **Сегменты JSON (для пайплайнов):** запуск с `--for multilingual-audio-replacement`
  (или явным `--debug-segments`)
  → рядом с MD пишется `~/result-mlx-whisper/YYYY-MM-DD_<имя>.segments.json`:
  `{"file": ..., "segments": [{"start", "end", "text", "logprob"}, ...]}` — сегменты
  VAD-пайплайна с таймингами в секундах и avg_logprob Whisper. Путь не настраивается.
- **`split_into_sentences(segments)`** в `vad_transcribe.py` — импортируемая функция:
  словопоток с интерполированными таймингами → предложения по финальной пунктуации.
- **Word timestamps:** vad_transcribe их не пишет; нужны пословные тайминги — сырой
  mlx_whisper с `--word-timestamps True --output-format json` (см. Quick Reference).
- **VAD — фильтр «речь vs не-речь», а не анти-шум**: Silero отбрасывает пение и
  неречевые звуки (замер: 59 с песни → 0 интервалов). Следствия:
  - проверочные транскрибации («стем пуст», «в финале не осталось исходной речи»,
    аудиореференс 3–10 с для клонирования) делать ТОЛЬКО сырым CLI — через
    vad_transcribe проверка пустоты проходит вакуумно, а из короткого сэмпла VAD
    может молча уронить тихую речь;
  - чистая песня на входе vad_transcribe → 0 сегментов — корректный результат
    «речи нет», а не сбой.
- **Точность таймингов VAD-пути**: старты сегментов/предложений запаздывают против
  пословных таймингов в медиане на ~0.2 с, максимум до ~0.6 с (замер на en-речи).
  Для монтажных нарезок по этим таймингам брать padding 0.2–0.25 с, а не 0.1 с.

## Procedure

1. **ГЕЙТ — определить язык ДО запуска, иначе не запускать вообще** (запуск с чужим языком —
   полная потеря работы и полный перезапуск). Порядок:
   а. Взять язык из самого источника: заголовок/описание (для YouTube — `yt-dlp --print "%(title)s | %(description)s"` — доступно ДО скачивания), метаданные, субтитры.
   б. Если источник неинформативен — прогнать детект на первых 30 с сырым mlx_whisper БЕЗ `--language` (или short-фрагмент) и прочитать `language` из результата.
   в. Перед запуском полного файла убедиться: в команде стоит явный `--language <detected>` и ты можешь назвать, ИЗ КАКОГО ИСТОЧНИКА взят этот язык («так в заголовке», «детект на 30 с дал en»). Не можешь назвать источник — стоп, гейт не пройден.
   г. Язык из памяти о прошлых задачах / привычки / дефолта («обычно всё русское») — ЗАПРЕЩЁН как источник.
2. Запустить по Quick Reference; для длинных файлов — `terminal(background=true, notify_on_complete=true)` + `process wait`. Скрипт печатает прогресс по этапам и `OK <путь>`.
3. Прочитать созданный MD (`read_file`), показать пользователю текст.
4. Нужен srt/перевод/фрагмент — сырой mlx_whisper из Quick Reference (не забывать `--condition-on-previous-text False`).

## Pitfalls

- **Путь модели — папка, не HF-id**: с локальной папкой работает офлайн и без сюрпризов кэша HF.
- **Модель выбирается по `--language` автоматически**: ru → podlodka q8, всё остальное →
  whisper-large-v3-turbo-8bit; `--model <папка>` перекрывает выбор. Для не-ru языка папка
  `~/.local/share/models/whisper-large-v3-turbo-8bit/` обязана существовать — иначе скрипт
  упадёт на старте с понятной ошибкой (podlodka для не-ru не годится: она ru-специализирована).
- Галлюцинации на тишине/музыке: повторяющиеся фразы = признак. Лечится `--condition-on-previous-text False`:
  в скриптах скилла включено всегда; в сырых вызовах передавать руками — убирает петли-повторы
  и восстанавливает фразы, потерянные после музыкальных вставок.
- VAD-пайплайн требует: venv `~/.local/share/stt-vad/` (onnxruntime+numpy), Silero onnx
  `~/.local/share/models/silero-vad/silero_vad.onnx`, ffmpeg. Запускать именно uv-tool питоном
  (`~/.local/share/uv/tools/mlx-whisper/bin/python`) — там mlx.
- `--fp16` флаг CLI не трогать: он про float16 при декодировании в оригинальном whisper, не про формат весов.
- Русские таймстампы srt сдвигаются на паузах — для точного монтажа включать `--word-timestamps True`.
- **Whisper пишет составные числительные одним числом**: сказанное «тысяч четыреста»
  становится в транскрипте `1400`, «двести пятьдесят тысяч» → `250000`. При чтении
  транскрипта и пересказе трактовать такие числа по контексту фразы, а не буквально:
  «200к достаточно, но было бы неплохо 1400» — это 400 тысяч, а не «1,4 тысячи тысяч».
- Если нужен другой квант (q4 — меньше RAM, fp16 — чуть точнее): скачать соотв. папку из того же HF-репо рядом и передать её путь.

## Verification

1. Скрипт напечатал `OK ~/result-mlx-whisper/YYYY-MM-DD_<имя>.md`; файл существует и непустой (`read_file`): шапка с блоком контент-метаданных (Название/Автор/Дата публикации/Ссылка) и техническими строками (дата, источник, длительность, модель, время) и транскрипт блоками `**mm:ss** текст` с пустой строкой после каждого блока.
2. Имя файла начинается с сегодняшней даты `YYYY-MM-DD_`.
3. Процесс завершился: `pgrep -fl mlx_whisper` пуст — модель выгружена из RAM (норма CLI-процесса).
4. Для длинного аудио сверить длительность последнего сегмента с ffprobe-duration.
